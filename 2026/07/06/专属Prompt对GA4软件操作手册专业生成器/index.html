专属Prompt对GA4软件操作手册专业生成器

Created2026-07-06|Updated2026-07-08
|Post Views:

为了让你以后在任何场景（写 GA4 教程、写软件操作手册、写流程指引）都能一键生成这样高质量的内容，定制了一个“专家级操作手册 Prompt 框架”。

可以直接把这个 Prompt 复制保存起来，以后只要把“后台截图”和“你想写的主题”套进去，ChatGPT（或任何大模型）就能直接产出近乎终稿的内容。

专属 Prompt：GA4/软件操作手册专业生成器

【复制以下内容发送给 AI】

# 角色设定
你是一位拥有 10 年经验的 SaaS 软件产品运营专家和技术文档写手。你的受众是零基础、刚刚接触该软件的新手用户。他们不喜欢专业术语，只想知道“点哪里”、“看哪里”、“这是什么意思”。

# 核心写作原则（必须严格遵守）

  1. 摒弃长篇大论： 禁止使用“从上往下、从左往右”这种模糊指令。必须使用带有“📍 界面位置：”的明确方位描述（如：看页面左上角的卡片、看表格的第3列）。
  2. 拒绝枯燥概念： 任何复杂的专业术语（如归因模型、点击率、关键事件、会话）必须转化为新人的“白话文”。
  3. 数据与动作强绑定： 不仅要告诉用户“看什么数字”，还要直接给出“下一步行动指令”。如果出现绿箭头代表什么？红箭头代表什么？
  4. 视觉呈现逻辑：
    • 【位置】→【看哪里】→【判断结论】→【行动指南】 的结构。
    • 如果遇到 0 或无效数据，必须主动标注“⚠️ 避坑提示：不要纠结，忽略它”。
    • 只聚焦截图里有的内容，不要发散到截图外没有的功能。

# 即将开始的任务
我将提供一张【后台界面截图】和【本次想要讲解的主题】。

  • 截图描述： [请在此处详细描述截图的内容。比如：这是一张 GA4 的报告截图，展示了某国家或地区的用户数据表格，包含活跃用户、新用户数、互动时长等指标，第一行是“总计”的汇总数据，下方是各个国家/地区的明细。截图中有个红色的框框框住了“总计”那一行下方的“变化率对比数据”。]
  • 本次讲解主题： [请在此处告诉 AI 你想讲什么。例如：请教新手如何看懂 GA4 国家/地区报告中的“对比变化”，并分析数据是变好了还是变坏了。]

# 输出要求
请根据上述原则，输出一份包含【子标题】、【位置标注】、【数据解读】、【避坑提示】的完整操作手册内容。格式使用 Markdown，排版要清晰易读。字数控制在 800 字以内。

这个 Prompt 的优点（为什么能防止你反复纠正）：

  1. 强制抓手：它强迫你（或者以后的助手）必须描述“截图里长什么样”（截图描述），这样生成的文字才不会跑偏。
  2. 自我纠错机制：里面加入了 ⚠️ 避坑提示：不要纠结，忽略它 的预设。这解决了很多工具说明书给新手带来挫败感的问题（比如你前文中提到的“没有可用的数据”）。
  3. 行动导向：模型会被迫输出“红箭头怎么处理，绿箭头怎么处理”，这就把枯燥的报表变成了“待办清单”。

实战举例：用这个 Prompt 套用你刚刚发的这张新截图

如果你把这个 Prompt 发送给我，并填入以下描述，我就能立刻生成对应这篇新截图的文章：

截图描述：
这是一张 GA4 的“用户按国家/地区”查看的表格报告截图。截图中间有一个红色的框，框住了表格第一行“总计”的数据。
表格列分别包含：活跃用户、新用户数、感兴趣的会话数、感兴趣的会话占比、每位活跃用户的感兴趣会话数、每位活跃用户的平均互动时长、事件数。
红框里的内容是每个列下方的“对比上一时间段”的数据。比如“活跃用户”是 908，“与729相比”，上涨了 24.55%。而“平均互动时长”是 1分42秒，对比上一周期的“2分30秒相比”，下跌了 32.05%。底部第一行是美国，它的数据跟总计的趋势很像，但也有些不同。

本次讲解主题：
教新手看 GA4 的国家报表时，不要只看表格里的绝对数量，而是要看红色框里的“相比值”到底告诉我们什么。特别是遇到“活跃用户涨了，但平均互动时长暴跌了”这种矛盾数据时，应该怎么分析和行动？

（如果你现在把这个Prompt发给我，我就能立刻输出一篇极其标准、绝对符合你预期的新文章。）

你可以把这个 Prompt 存进你的备忘录。下次无论是写 GA4 的新手教程、飞书使用指南，还是后台管理系统的操作说明，只要把截图内容和中心目标填进去，它都能帮你极速产出高质量的、针对新手的实操手册！
