如何通过安装与配置AllPays插件在WooCommerce独立站中安全接入Polygon链USDC跨境支付网关

问：什么是AllPays网关？在WooCommerce中使用它有什么优势？

答：AllPays（AllPays.co）是一个专为跨境电商设计的创新支付网关，支持全球范围内的信用卡、Apple Pay、Google Pay等主流法币支付渠道。对于WooCommerce商家而言，它的最大优势在于无需繁琐的KYC（身份验证）或复杂的企业注册流程即可快速启用。当海外客户在您的独立站使用法币付款后，AllPays系统会自动将资金结算为加密货币（Polygon链上的USDC代币）并直接转入您的个人钱包，极大地简化了跨境收款与变现的门槛。

问：作为零基础的小白，应该如何一步步在WooCommerce中安装AllPays插件？

答：请按照以下三个简单步骤进行操作，无需编写任何代码：

  1. 登录您的WordPress网站后台，在左侧导航菜单中找到并点击 **插件 (Plugins)**，随后选择 **安装插件 (Add New)**。
  2. 移动鼠标到页面右上角的搜索框，输入插件名称 AllPays.co 并按下回车进行检索。
  3. 在搜索结果中找到名为 AllPays.co – Payment Gateway for WooCommerce 的插件，点击它右上角的 现在安装 (Install Now) 按钮。等待几秒钟安装完成后，该按钮会变成蓝色，点击 启用 (Activate) 即可让插件正式生效。

问：插件启用后，我该去哪里找到它的配置页面？

答：请跟随以下路径进入设置后台：

  1. 在WordPress后台左侧的主菜单中，将光标悬停在 WooCommerce 上，并在弹出的子菜单中点击 **设置 (Settings)**。
  2. 进入设置页面后，点击顶部导航栏中的 付款 (Payments) 选项卡。
  3. 此时您会看到网站所有的支付方式列表。在列表中找到 AllPays.co 或 AllPays，点击其右侧对应的 管理 (Manage) 按钮，然后启用这个收款功能，即可进入核心参数的配置界面。

问：进入AllPays配置页面后，面对各种英文输入框，小白应该如何准确填写？

首先：你需要去AllPays.co创建一个钱包信息，地址：https://allpays.co/create-payment-link，在这里生成钱包地址，每一笔订单最小金额是10，对于销售产品来说几乎都是十几块，上百块，甚至上千块的吧，这个应该保持默认的10块就行了，想要设置高一点完全没问题，但是不能比10小。

    • 如何填写： 必须在此处填入您个人的加密货币钱包地址（例如通过 MetaMask、Trust Wallet 等钱包生成的地址）。请确保该地址能够接收 Polygon网络（Matic链） 上的资产。这里就填写：0x4bf71704cdd3bn32g7d7554986aa2dvfe193efa64
    • 小白敲黑板： 这是最核心的步骤！该地址用于接收客户付款结算后的 USDC 代币。由于区块链转账具有不可逆性，请务必反复核对每一个字符。如果填错地址，您的辛苦收入将永久丢失，任何人都无法帮你找回。
  2. GATEWAY MODE（网关模式）
    • 如何选择： 页面提供了两个选项，强烈建议保持默认的 **AllPays Gateway (Recommended)**。
    • 为什么： 此模式会自动为您的网站优化结账流程，向客户展示一个由官方托管的、体验顺畅的结算页面。另一个“Providers Mode”则是允许客户在结账时自己去挑选底层的特定支付服务商，对普通小白用户来说体验较为繁琐。
  3. ADD FEE/DISCOUNT（添加手续费/折扣）
    • 如何填写： 这是一个灵活的调价工具。
      • 如果您希望向客户额外收取手续费（转嫁成本），请输入正数，例如输入 5% 或固定金额 10。
      • 如果您希望给使用该通道的客户提供付款优惠，请输入负数，例如输入 -5%。
      • 如果您不想额外加价也不想打折，直接保持完全留空即可。
  4. WHO COVERS PARTNER PAYMENT FEES（谁承担合作伙伴支付手续费）
    • 如何选择： 页面提供两个单选按钮。
      • Merchant（商家）： 意味着支付通道产生的手续费由您自己承担，会从您的结算总额中扣除。客户在结账时看到的金额就是最终支付金额。为了保证良好的消费者购物体验，强烈推荐选择此项。
      • Customer（客户）： 手续费会自动累加到客户的订单总额里，让消费者买单，这可能会降低客户的付款意愿。
  5. REMINDER EMAIL INSTRUCTIONS（催款邮件说明）
    • 如何填写： 在文本框中输入您想自动发送给未付款客户的催款文案（例如：“亲爱的客户，您的订单尚未完成支付，请点击以下链接继续完成付款以确保商品及时发出”）。
    • 启用条件： 仅填写文案是不够的，您必须将该框下方的 Reminder emails 开关切换为绿色（启用状态），并自由设定发送时间（如订单关闭后 60 分钟、1天或2天后），这套自动催款系统才会正式工作。
  6. API KEY (Optional)（API 密钥 - 选填）
    • 如何填写： 这是一个高级选项，请直接保持完全留空。正常收款完全不需要使用它，除非未来有官方客服明确要求您对接特定高级功能，如果想要填写，就填写这个：hQM5hDdmUfTKShw566cf47K16uvhAVYPAAxlsYCeJlYWIZ1fqtgw1pjt6ULXXXXX

问：所有内容填好后，如何保证设置不丢失并正式开通收款？

答：当您仔细核对完上述所有选项后，请将页面滚动到最下方，找到并点击蓝色的 Save changes（保存更改） 按钮。系统提示保存成功后，AllPays支付网关就正式在您的独立站前台结账页面上线了，此时您可以尝试进行一笔低额度测试来确保流程完全畅通。

一、AllPays.co是什么？它来自哪个国家？

AllPays.co是一家来自以色列的支付服务提供商，主要为独立站商家（尤其是使用WooCommerce的商家）提供信用卡收款通道。根据WordPress官方插件页面的开发者资料，该公司注册地明确为Israel。

对于新手商家来说，了解这一点很重要，因为这意味着：

  • 该平台的《服务条款》等法律文件很可能适用以色列法律
  • 它服务全球客户，国际信用卡交易会收取额外费用
  • 资金结算方式与传统支付网关有所不同

二、AllPays.co的套餐有哪些？我该怎么选？

AllPays.co提供三个套餐层级，核心逻辑很简单：月费越高，每笔交易的手续费越低。

Start套餐（免费）

  • 月费：$0
  • 每笔交易手续费：10%
  • 包含：所有集成方式（WooCommerce插件、支付链接、API等）、托管结账页面、基础交易可见性、1个操作席位、社区文档支持
  • 不包含：品牌化结账、支出报告、邮件支持

Launch套餐（$79/月）

  • 月费：$79
  • 每笔交易手续费：8%
  • 包含：Start所有功能 + 品牌化结账、支出报告、邮件支持
  • 年付可节省20%

Growth套餐（$249/月）

  • 月费：$249
  • 每笔交易手续费：5.9%
  • 包含：Launch所有功能 + 智能路由、失败重试/故障切换界面、自定义域名设置、深度分析报告、优先技术支持
  • 年付可节省20%

三、我是刚起步的中小企业，交易量不高，应该选哪个？

根据你”刚开始、交易量不高、想分担风险”的情况，强烈建议从Start免费套餐开始。

理由有三：

  1. 零固定成本：月费$0，意味着你以零成本获得了一个完整的备用支付通道。有订单才产生10%的手续费，没订单不花一分钱——完美匹配”分担风险”的需求。

  2. 核心功能完整：WooCommerce插件集成、托管结账、API和Webhook全部包含，技术上完全可以跑通支付流程。

  3. 升级路径清晰：当交易量增长到一定程度后，可以随时升级到Launch或Growth，不会被锁定。

什么时候该考虑升级？

升级到Launch（$79/月）的时机 升级到Growth（$249/月）的时机
月销售额稳定超过约$3,950时（此时省下的2%手续费超过$79月费） 需要智能路由提升支付成功率、自定义域名、深度分析或优先支持时
开始重视品牌形象，希望结账页面显示自己的品牌而非AllPays标识时 月销售额足够大，5.9%低费率带来的节省远超$249月费时

四、交易手续费是怎么收的？每笔都收吗？

是的，交易手续费按每笔成功交易收取。但需要注意的是，手续费不是只有一个固定比例，而是由几个部分叠加构成：

套餐基础费率

  • Start：10%
  • Launch：8%
  • Growth：5.9%

额外叠加费用

除了套餐费率外，实际使用信用卡收款时还会有这些附加成本：

费用类型 费率/金额
境内Visa/Mastercard 1.45%
国际Visa/Mastercard 3.65%
美国运通/大莱卡 额外+0.5%
商务卡 额外+1.5%至1.75%
3D安全验证 0.2%/笔
退款手续费 3.9 ILS（以色列新谢克尔）/笔

这意味着，如果一笔交易使用的是国际信用卡且带有商务卡属性，总手续费会显著高于套餐标明的费率。新手商家在定价时，需要把这些潜在成本考虑进去。

五、客户付款后，钱去了哪里？

当客户在你的独立站使用AllPays.co完成付款后，资金流向是这样的：

  1. 处理环节：AllPays.co的合作伙伴收单机构（持牌信贷机构）处理该笔交易
  2. 结算环节：资金结算到你的AllPays钱包余额中
  3. 重要说明：根据AllPays的服务条款，AllPays本身并不持有商户资金，它们只是通过第三方支付处理商来协助完成交易流程

对于新手商家来说，这意味着AllPays更像是一个”技术桥梁”，而不是一个”资金池”。

六、如何把钱包里的钱提出来？需要手续费吗？多久到账？

提现方式

AllPays提供两种提现方式：

自动提现（默认）

  • 每月6号自动处理上月收到的所有付款
  • 适合不想手动操作的商家

手动提现

  • 你可以关闭自动提现，随时手动发起提现请求
  • 适合希望灵活控制资金节奏的商家

提现费用

  • 提现金额达到或超过5,000 ILS（约合1,350美元）：免手续费
  • 提现金额低于5,000 ILS：收取 17.58 ILS（含增值税）的银行手续费

到账时间

提现发起后，通常需要最多3个工作日才能到达你的银行账户。

最低提现限额

  • 最低提现金额为 100 ILS / USD / EUR
  • 你也可以设置一个自动触发阈值（例如余额达到5,000 ILS时自动提现），以避免小额提现产生手续费

七、遇到交易纠纷，AllPays会帮忙处理吗？

会的，但处理方式是”协助”而非”全权代理”。

当发生争议（例如客户发起拒付/争议）时，流程如下：

  1. AllPays会通知你发生了争议
  2. AllPays可能会请求相关的支付处理商或收单机构对交易进行审核
  3. 根据审核结果，可能会采取暂停、延迟、退款或撤销该笔交易的操作
  4. 需要明确的是：AllPays不会独立执行这些操作，而是遵循支付处理商和卡组织（如Visa、Mastercard）的规定程序
  5. 作为商家，你需要积极配合并提供交易证据

对于新手商家，建议保留好每一笔交易的完整记录（包括客户信息、商品描述、发货凭证等），以备不时之需。

八、能开发票吗？

AllPays平台提供了生成和获取发票的功能。但根据其服务条款，有一个关键注意事项：

发票可能并非始终可访问，商户有责任自行下载并安全保存所有已生成发票的副本。

这意味着：

  • 平台可以生成发票，但你不应完全依赖平台长期保存
  • 务必每次生成后立即下载并备份到自己的存储系统
  • 这关系到你的财务记录和税务申报，不要忽视

九、新手常问的其他问题

AllPays支持哪些支付方式？

主要支持信用卡支付，包括Visa、Mastercard、美国运通、大莱卡等主流卡品牌。具体支持范围可能会根据商户所在地区和业务类型有所调整。

钱包结算是什么意思？

简单来说，就是客户支付的资金先进入你在AllPays平台上的”虚拟钱包”余额中，然后你再从钱包提现到自己的银行账户。这不是一个加密货币钱包，而是一个记录你待结算资金余额的账户系统。

以后可以切换套餐吗？

可以。AllPays允许商户根据业务发展情况随时切换套餐，这给了新手商家很大的灵活性——先用免费计划起步，业务增长后再升级。

提供什么样的技术支持？

  • Start套餐：仅限文档和社区支持
  • Launch套餐：邮件支持
  • Growth套餐：优先技术支持

十、给新手商家的最终建议

  1. 从Start免费套餐起步：零成本接入，先跑通流程，分担主支付渠道的风险
  2. 保存好每笔交易记录：既是财务需要，也是应对潜在纠纷的证据
  3. 关注月销售额临界点：当销售额稳定在$4,000/月以上时，考虑升级到Launch
  4. 提现尽量攒够5,000 ILS：可以免去17.58 ILS的提现手续费
  5. 发票及时下载备份：不要只依赖平台存储
  6. 国际卡交易成本更高：定价时要把3.65%的国际卡费率考虑进去

比特币家庭挖矿常见术语解释
比特币家庭挖矿常见术语解释Hashrate（算力）算力是设备每秒能够执行的哈希计算次数。 简单理解： 算力越高，相当于买彩票的次数越多，因此获得区块奖励的概率也会相应提高。 常见单位： GH/s = 十亿次计算每秒 TH/s = 万亿次计算每秒 PH/s = 千万亿次计算每秒 EH/s = 百亿亿次计算每秒 Hash（哈希）哈希是一种固定长度的数字指纹。 比特币使用 SHA-256 算法，每次计算都会生成一个新的哈希值。 矿机实际上是在不断尝试寻找符合条件的哈希结果。 Nonce（随机数）Nonce 是矿工不断改变的参数。 每次改变 Nonce，都会产生新的哈希值。 可以把它理解为： 不断更换彩票号码，直到中奖为止。 Block（区块）区块是比特币网络记录交易数据的容器。 平均每十分钟产生一个新区块。 每个新区块都会连接到前一个区块，因此形成区块链。 Block Reward（区块奖励）成功发现新区块后，矿工能够获得对应的 BTC 奖励。 目前奖励由： 新产生的 BTC 用户支付的交易手续费 两部分组成。 Difficulty（难度）难度代表找到有效区块的困难程度。 网络...
